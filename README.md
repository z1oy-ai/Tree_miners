# Tree Chop MiniGame — Stage 1

Minecraft 26.2
Fabric
Java 25

Stage 1 contains the first playable visual prototype.

The mini-game appears when the player aims at a log while holding an axe and starts an attack.

Current prototype:
- central circular interface
- rotating axe
- two green timing zones
- SPACE prompt
- client-side HUD rendering

Stage 2 will add timing validation, five hits, misses and completion logic.
